# 📚 Study Archive

AI와 함께 공부한 내용을 자동으로 구조화 기록하고, 디바이스·계정에 종속되지 않게 관리하는 개인 학습 아카이브.

## 무엇을 하나
- **자료정리** — 강의 자료를 AI와 구조화해 정리
- **모의면접** — 면접 연습 + 약점 진단
- 결과는 **Notion**(1차) + **로컬 마크다운**(백업)에 자동 기록
- 어느 PC/계정에서든 이어서 학습 (→ [SETUP.md](SETUP.md))

## 구조
```
Study-Archive/
├─ CLAUDE.md          # AI 행동 지침 (장기 기억)
├─ SETUP.md           # 새 환경 재현 가이드
├─ Notes/             # 자료정리 기록
├─ Interviews/        # 모의면접 리포트
└─ .claude/settings.json  # 폴더 외부 접근 차단 권한 설정
```

## 사용법
Claude Code를 이 폴더에서 열고:
- `시작` — 지난 진도·약점 브리핑
- 자료 업로드 / `모의면접` — 학습 진행
- `기록` — 저장
