## 개념: MST (최소 신장 트리)

### Q1. 정의
- **내 답변 요약**: 가중치 합이 최소인 트리. "spanning"의 뜻은 모름.
- **평가**: 🟡 트리 정의(N노드/N-1간선/모든노드연결/유일경로)는 정확.

### Q1-tail. 모든 정점 포함 여부
- **내 답변 요약**: 다 포함되어야 함.
- **평가**: 정확.

### Q2. Kruskal/Prim 메커니즘
- **내 답변 요약**: 이름 헷갈림. 간선중심(정렬+union-find)/노드중심(우선순위큐) 메커니즘은 정확히 설명.
- **평가**: 🟢 메커니즘 정확.

### Q3. 복잡도·sparse/dense
- **내 답변 요약**: Kruskal O(ElogE), 힙 기반 Prim O(ElogV). sparse/dense 선택은 구현과 그래프 표현에 따라 달라지며, dense graph에서는 배열 기반 Prim O(V²)이 특히 유리할 수 있음.
- **평가**: 🟡 일반적인 선택 방향은 맞았으나 배열 기반 Prim의 근거를 설명하지 못함.

### Q4. Array 기반 Prim (핵심 약점)
- **내 답변 요약**: 힌트(배열+선형탐색) 후에도 플로이드-워셜(O(V³), 전혀 다른 알고리즘)로 답이 새어나감.
- **평가**: 🔴 미해소.
- **모범답안**: dist[] 배열을 V번 선형탐색해 최솟값 트리에 추가(O(V)), 인접 간선 갱신(O(degree)). 전체 O(V²)+O(E)=O(V²). dense(E≈V²)에서 힙 기반 O(ElogV)=O(V²logV)보다 유리.

## 개념: 위상 정렬 (Topological Sort)

### Q5. 정의
- **내 답변 요약**: DAG에서만 성립.
- **평가**: 정확.

### Q6. 사이클 불가 이유·Kahn's 알고리즘
- **내 답변 요약**: 사이클 있으면 선후관계 정의 불가. in-degree=0 노드를 큐에 넣는 방식.
- **평가**: 정확.

### Q7. 사이클 판별
- **내 답변 요약**: 모든 노드가 큐에 삽입 안 되면 사이클 존재.
- **평가**: 정확.

### Q8. 복잡도
- **내 답변 요약**: 처음 O(E) 오답 → 반례(고립 정점 100개) 힌트 후 O(V+E)로 정정.
- **평가**: 힌트 후 회복.

## 개념: SCC (강한 연결 요소)

### Q9. 정의
- **내 답변 요약**: 처음 "모든 쌍 간 직접 간선"으로 오답 → 힌트(상호 도달가능성) 후 "방향그래프+모든 쌍 상호 도달 가능"으로 정정.
- **평가**: 힌트 후 회복.

### Q10. SCC 알고리즘 (핵심 약점)
- **내 답변 요약**: naive(전체 노드 BFS) O(V(V+E)) 정확. 방향그래프 전용 O(V+E) 알고리즘은 전혀 모름. 힌트(전치 그래프) 후에도 미해소, 다만 "위상정렬과 관련 있을 것 같다"는 유효한 직관 제시.
- **평가**: 🔴 미해소(직관은 정확한 방향).
- **모범답안**: Kosaraju's Algorithm — ①원본 그래프 DFS로 종료시각 순 스택 적재 ②전치 그래프(간선 방향 전부 반전) 생성 ③종료시각 역순으로 전치 그래프에서 DFS, 각 트리가 SCC. 전체 O(V+E). 대안: Tarjan's(한 번의 DFS + low-link 값). "위상정렬과 관련 있다"는 직관은 실제로 정확 — 종료시각 기반 정렬이 핵심 원리 공유.

---

### 약점·복습포인트 (그래프 알고리즘)
- 배열 기반 Prim O(V²)의 원리를 바로 떠올리지 못함
- 방향그래프 SCC를 O(V+E)에 구하는 Kosaraju's/Tarjan's 알고리즘 자체를 모름
- 위상정렬 복잡도 O(E)가 아니라 O(V+E)(고립 정점도 push/pop 비용)

### 이해도: 🟡 보통 (MST의 배열기반 Prim과 SCC 알고리즘이 핵심 약점, 위상정렬은 힌트 후 대부분 회복)
