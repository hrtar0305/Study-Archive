## 개념: 힙 (Heap)

### Q1~Q2. 정의·속성
- **내 답변 요약**: 우선순위 큐 구현용 자료구조. 부모가 자식보다 항상 작거나(min) 크면(max) 힙.
- **평가**: 정확. **보완** — 힙 속성은 부모-자식 간 국소 규칙일 뿐(형제·다른 서브트리 간 순서 없음 → 정렬된 구조가 아님).

### Q3~Q5. 완전 이진 트리·배열 표현·인덱스
- **내 답변 요약**: binary tree, 실제로는 array 저장. 1-index(부모 i/2, 자식 2i·2i+1, 0번 더미)와 0-index(부모 (i-1)/2, 자식 2i+1·2i+2) 모두 정확히 유도.
- **평가**: 인덱스 산술 완벽. **보완(중요)** — Q3에서 '이진 트리'라고만 했으나 정확히는 **완전 이진 트리(complete binary tree)**. 이 완전성이 배열에 빈틈없이 담기고 인덱스 산술로 O(1) 접근을 가능케 하는 전제.

### Q6~Q8. 삽입·삭제·sift-down
- **내 답변 요약**: 삽입 = 맨 끝 추가 후 sift-up O(log N). 삭제 = 루트 반환 → 마지막 원소를 루트로 → sift-down O(log N). sift-down 시 min heap은 두 자식 중 더 작은 값과 swap(아니면 재위반).
- **평가**: 모두 정확.

### Q9~Q11. Heapify O(N) 증명
- **내 답변 요약**: heapify O(N). 리프에 가까울수록 연산 적음. sift-up 방식은 리프(N/2)가 최악 logN칸 이동해 O(NlogN), sift-down은 N/2가 0회·N/4가 1회…로 수렴.
- **평가**: 천장 도달. 스스로 정량적 직관 제시.
- **모범답안(정량화)**: 비용 = Σ(N/2^(h+1))·h = N·Σ h/2^(h+1) = N·O(1) → O(N). sift-up은 Σ(N/2^(h+1))·(높이-h)라 다수 노드가 큰 거리 → O(NlogN).

### 사용자 질문 — 왜 이진(d=2)인가 (d-ary 힙)
- 자식 d개면 높이는 log_d N. d가 커지면 높이는 낮아져 sift-up은 대체로 유리하지만, sift-down은 각 레벨에서 d개 자식 중 최솟값을 찾아야 한다. 따라서 삽입은 Θ(log_d N), 삭제는 Θ(d·log_d N)의 trade-off를 가지며, 이진은 균형과 구현 단순성을 갖춘 실용적 기본값이다.
- **d-ary가 유리한 사례**: decrease-key(sift-up 계열)가 extract-min보다 훨씬 잦을 때 — dense 그래프 다익스트라에서 4-ary 힙이 이진보다 빠를 수 있음(트리를 낮춰 잦은 sift-up을 싸게).

### 사용자 요청 — 연관 알고리즘 Top-K
- **문제**: N개 중 가장 큰/작은 K개 구하기. 전체 정렬 O(N log N)은 K개만 필요한데 전부 정렬하는 낭비.
- **크기 K 힙 (핵심)**: K개 최댓값 → **크기 K의 min-heap** 유지. N개를 하나씩 넣되 K 초과 시 루트(현재 후보 중 최솟값) 제거 → 끝나면 top-K. **시간 O(N log K), 공간 O(K)**. min-heap을 쓰는 이유: 루트가 후보 중 최솟값이라 새 원소가 그보다 크면 바로 밀어냄.
- **Quickselect**: 메모리에 다 있으면 평균 O(N), 단 worst-case O(N²)·스트리밍 불가.
- **힙이 sort보다 유리한 지점**: ① K≪N일 때 O(N log K)≪O(N log N) ② 후보 K개만 작업 메모리에 유지 ③ **스트리밍/온라인 데이터**에서 전체 N개를 저장하지 않고 처리. 전체 정렬 알고리즘의 추가 공간은 구현에 따라 O(1)~O(N)이므로, 여기서의 핵심 비교는 auxiliary space 단정이 아니라 전체 입력 보관 필요 여부다.
- **선택 기준**: K≪N·스트리밍·top-K만 필요 → 힙 / 전체 정렬 순서 필요하거나 K가 N에 가까움 → sort / 전부 메모리에 있고 평균 O(N) 필요·스트리밍 아님 → quickselect.

### 약점·복습포인트 (힙)
- (거의 없음, 천장 도달) 굳이 꼽으면 '완전 이진 트리' 용어를 처음에 명시하지 않은 점
- heapify O(N) 증명(레벨별 노드수 × 하강거리 급수 수렴) 재확인용
- d-ary 트레이드오프 / Top-K에서 크기 K min-heap 패턴
