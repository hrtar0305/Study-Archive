## Q1. Wi‑Fi와 유선 이더넷의 차이

- **질문**: Wi‑Fi란 무엇이며 유선 이더넷과 비교했을 때 가장 본질적인 차이는 무엇인가?
- **내 답변 요약**: Wi‑Fi는 유선이 아닌 무선으로 패킷을 통신하는 방식이고, 이더넷과는 전달 매체가 LAN 케이블인지 공기인지가 다르다고 답했다.
- **평가**: Wi‑Fi가 공기 중 전파를 매체로 사용한다는 핵심은 맞았다. 다만 차이를 물리 매체에만 한정했다. Wi‑Fi는 일반적으로 여러 단말이 하나의 채널과 airtime을 공유하지만 현대의 스위치드 이더넷은 각 포트가 독립적인 전이중 링크를 사용할 수 있다는 차이도 중요하다.
- **모범답안**: Wi‑Fi는 IEEE 802.11 계열의 무선 LAN 기술이다. 전파를 사용하고 여러 단말이 같은 채널을 공유해 경쟁한다. 현대의 스위치드 이더넷은 일반적으로 단말과 스위치 사이에 독립적인 전이중 링크를 제공한다.

## Q2. 같은 채널의 동시 송신

- **질문**: 같은 Wi‑Fi 채널을 여러 기기가 공유할 때 두 기기가 동시에 송신하면 어떤 문제가 발생하는가?
- **내 답변 요약**: 무선 통신은 주파수 기반이므로 둘 이상의 기기가 같은 채널·주파수 대역을 동시에 사용하면 전파 간섭이 발생한다고 답했다.
- **평가**: 공유 채널에서 신호가 겹쳐 간섭이 생긴다는 핵심은 맞았다. 수신기가 프레임을 정상적으로 복호화하지 못해 손실과 재전송이 발생하며, 이를 줄이기 위해 매체 접근 순서를 조정해야 한다는 점까지 연결할 필요가 있다.
- **모범답안**: 같은 채널에서 두 단말이 동시에 송신하면 수신기에서 신호가 중첩되어 프레임을 정상적으로 복호화하지 못할 수 있다. Wi‑Fi는 공유 매체의 충돌 가능성을 줄이기 위해 CSMA/CA와 ACK·재전송을 사용한다.

## Q3. 무선에서 충돌 감지가 어려운 이유

- **질문**: 송신 중인 무선 기기가 자신의 전송과 다른 기기의 충돌을 동시에 구분해 감지하기 어려운 이유는 무엇인가?
- **내 답변 요약**: 처음에는 정확한 이유를 모르겠다고 답했다. 자기 송신 신호와 멀리 있는 다른 기기의 약한 신호를 비교하라는 힌트 후, 거리별 신호 세기가 달라 간섭인지 노이즈인지 구분하기 어렵다고 추론했다.
- **평가**: 거리와 신호 세기 차이에 주목한 것은 관련 있는 추론이다. 핵심은 자기 안테나 근처의 매우 강한 송신 신호가 멀리서 도달하는 약한 신호를 압도하고, 일반적인 무선 장치가 같은 채널에서 송신하면서 동시에 약한 수신 신호를 정확히 판별하기 어렵다는 점이다. 두 단말이 서로는 듣지 못하지만 AP에는 모두 도달할 수 있는 숨은 단말 문제도 있다.
- **모범답안**: 무선 장치는 일반적으로 같은 채널에서 송신과 수신을 동시에 정확히 수행하기 어렵고, 자신의 송신 신호가 다른 단말의 약한 신호보다 훨씬 강해 충돌을 송신 중 직접 감지하기 어렵다. 위치에 따라 다른 단말을 듣지 못하는 숨은 단말도 있으므로 Wi‑Fi는 CSMA/CD가 아니라 충돌 회피 중심의 CSMA/CA를 사용한다.

## 후속 학습

### Wi‑Fi의 공유 매체 특성

Wi‑Fi는 같은 채널을 사용하는 단말들이 airtime을 공유하는 반이중 통신 환경이다. 한 단말이 채널을 오래 점유하면 다른 단말들이 기다려야 한다. 표시된 PHY 링크 속도와 실제 애플리케이션 처리량이 다른 이유에는 다음 요소가 있다.

- MAC·PHY 헤더와 관리 프레임
- 채널 경쟁과 대기 시간
- ACK와 재전송
- 간섭과 신호 감쇠
- 낮은 전송률 단말의 긴 airtime 점유

### CSMA/CA

CSMA/CA는 충돌을 감지한 뒤 처리하기보다 전송 전에 충돌 가능성을 줄이는 방식이다. 전통적인 DCF의 단순화된 흐름은 다음과 같다.

1. 물리적·가상 carrier sense로 채널이 사용 중인지 확인한다.
2. 채널이 일정 시간 비어 있으면 바로 전송하지 않고 contention window에서 랜덤 backoff 값을 고른다.
3. 채널이 비어 있는 slot마다 backoff counter를 감소시킨다.
4. 다른 단말이 송신하면 counter를 멈추고, 채널이 다시 비면 이어서 감소시킨다.
5. counter가 0이 되면 데이터 프레임을 전송한다.
6. 수신자는 짧은 SIFS 뒤 ACK를 보낸다.
7. ACK를 받지 못하면 충돌·간섭·손실로 추정하고 contention window를 늘린 뒤 재시도한다.

```text
채널 감지
→ 유휴 대기
→ 랜덤 backoff
→ counter 0
→ 데이터 전송
→ ACK 수신 성공

ACK 없음
→ 손실 추정
→ contention window 증가
→ 재시도
```

Wi‑Fi의 QoS 확장인 EDCA에서는 트래픽 종류에 따라 대기 시간과 contention parameter를 다르게 설정할 수 있다.

### CSMA/CD와 CSMA/CA

- CSMA/CD: 과거 공유·반이중 이더넷에서 송신 중 충돌을 감지하고 중단
- CSMA/CA: Wi‑Fi에서 송신 전 채널 감지와 랜덤 backoff로 충돌 가능성을 줄이고 ACK 부재로 실패를 추정

현대의 스위치드 전이중 이더넷에서는 포트별 링크가 독립적이어서 일반적으로 CSMA/CD를 사용하지 않는다.

### 숨은 단말

단말 A와 C는 서로의 신호를 듣지 못하지만 둘 다 AP B에는 도달할 수 있다고 하자.

```text
A ─── B(AP) ─── C

A와 C는 서로 감지하지 못함
A와 C가 동시에 송신
→ B에서 충돌
```

A는 채널이 비었다고 판단하고 C도 채널이 비었다고 판단할 수 있으므로 carrier sense만으로 충돌을 막지 못한다.

### 노출 단말

한 단말이 이웃의 송신을 듣고 자신의 송신도 충돌할 것이라고 판단해 불필요하게 기다리는 문제다. 실제 수신기가 서로 충분히 떨어져 있어 두 전송이 동시에 가능할 수 있는데도 채널 사용을 포기해 공간 재사용 효율이 떨어진다.

### RTS/CTS

선택적으로 짧은 제어 프레임으로 매체를 예약할 수 있다.

```text
송신자 → AP: RTS
AP → 주변 단말: CTS
송신자 → AP: DATA
AP → 송신자: ACK
```

CTS를 들은 주변 단말들은 NAV를 설정하고 예약 시간 동안 송신을 미룬다. 숨은 단말이 송신자의 RTS는 못 들어도 AP의 CTS를 들을 수 있다면 충돌을 줄일 수 있다.

RTS/CTS 자체에도 오버헤드가 있으므로 모든 프레임에 항상 사용하는 것은 아니며, 큰 프레임이나 충돌 가능성이 높은 환경에서 이점이 커질 수 있다. 숨은 단말 문제를 완전히 제거한다고 단정할 수는 없다.

### 물리적·가상 carrier sense

- 물리적 carrier sense: 실제 무선 에너지를 감지해 채널 사용 여부 판단
- 가상 carrier sense: 프레임의 예약 시간 정보로 NAV를 설정해 채널이 예약됐다고 판단

### AP·STA·SSID·BSSID

- STA: Wi‑Fi에 접속하는 단말
- AP: 무선 단말과 유선 LAN을 연결하고 무선 셀을 제공하는 장치
- SSID: 사용자가 보는 네트워크 이름. 여러 AP가 같은 SSID를 사용할 수 있음
- BSSID: 특정 AP의 무선 인터페이스·BSS를 구분하는 식별자. 일반적으로 MAC 주소 형태

같은 SSID를 여러 AP가 제공해도 각 AP의 BSSID는 다를 수 있다.

### Wi‑Fi 연결 과정

단순화된 흐름은 다음과 같다.

1. Beacon을 수신하거나 Probe Request·Response로 AP 탐색
2. SSID·BSSID·채널·보안 방식 확인
3. 802.11 인증·Association 과정
4. WPA2·WPA3 방식에 따른 사용자·기기 인증과 키 설정
5. 암호화 키가 준비되면 데이터 프레임 송수신
6. 일반적인 IP 네트워크에서는 DHCP로 IP·게이트웨이·DNS 등을 획득

802.11 링크 연결과 IP 주소 획득은 다른 단계다. Wi‑Fi 연결이 완료되어도 DHCP가 실패하면 정상적인 IP 통신을 못 할 수 있다.

### 주파수 대역과 채널

#### 2.4GHz

- 비교적 긴 도달 거리와 벽 투과에 유리
- 사용할 수 있는 비중첩 채널이 적음
- Bluetooth·전자레인지 등 다른 장치와 간섭 가능
- 혼잡하기 쉬움

#### 5GHz

- 더 많은 채널과 넓은 채널 폭 사용 가능
- 일반적으로 높은 처리량과 낮은 혼잡 가능
- 2.4GHz보다 도달 거리·벽 투과가 불리할 수 있음

#### 6GHz

- Wi‑Fi 6E·7 등에서 사용
- 넓고 비교적 깨끗한 스펙트럼 제공 가능
- 도달 거리와 장애물 통과 측면의 제약이 더 클 수 있음
- 국가별 규제와 지원 기기 여부를 확인해야 함

채널 폭을 넓히면 높은 PHY 속도를 얻을 수 있지만 사용 가능한 독립 채널 수가 줄고 간섭 영향을 받을 가능성이 커질 수 있다.

### WPA2와 WPA3

#### WPA2

- 일반적으로 AES 기반 CCMP 사용
- Personal에서는 PSK, Enterprise에서는 802.1X·EAP와 인증 서버 사용 가능
- 약한 공유 비밀번호는 사전 공격에 취약할 수 있음

#### WPA3

- Personal에서 SAE를 사용해 공유 비밀번호 기반 인증을 개선
- 관리 프레임 보호를 강화
- 비밀번호 추측 공격에 대한 방어를 개선

WEP와 TKIP는 오래되고 취약하므로 사용하지 않아야 한다. WPA2·WPA3도 올바른 암호, 인증서 검증, 업데이트와 설정이 필요하다.

### 로밍

단말이 이동하면서 더 적합한 AP로 연결을 옮기는 과정이다. 일반적으로 단말이 로밍 결정을 내리며 802.11k·v·r 등이 후보 AP 정보와 빠른 전환을 도울 수 있다.

같은 L2 네트워크와 IP subnet 안에서 로밍하면 IP를 유지하고 기존 연결을 계속할 가능성이 크다. 다른 subnet으로 이동해 IP가 바뀌면 상위 계층 세션 유지가 더 어려워질 수 있다.

### 전송률 조절

Wi‑Fi는 신호 품질과 오류율에 따라 변조·코딩 방식인 MCS를 조정한다.

- 높은 MCS: 더 많은 비트를 보내 처리량이 높지만 신호 품질이 좋아야 함
- 낮은 MCS: 처리량은 낮지만 잡음과 감쇠에 더 강함

거리가 멀거나 간섭이 심하면 더 낮고 견고한 전송률로 내려갈 수 있다.

### OFDM·OFDMA·MIMO

- OFDM: 하나의 채널을 여러 직교 부반송파로 나누어 데이터를 전송
- OFDMA: 부반송파 묶음을 여러 단말에 나누어 같은 시간에 효율적으로 스케줄링
- MIMO: 여러 안테나를 이용해 여러 공간 스트림을 보내거나 수신 성능을 개선
- MU‑MIMO: 여러 단말과 동시에 공간 스트림을 사용
- Beamforming: 특정 단말 방향으로 신호 에너지를 집중해 품질 향상

OFDMA는 주파수 자원을 여러 사용자에게 나누는 기술이고, MIMO는 공간 차원을 활용한다는 차이가 있다.

## 예상 꼬리질문과 모범답안

### CSMA/CA는 어떻게 동작하는가

채널을 감지하고 유휴 상태가 되면 랜덤 backoff를 수행한다. counter가 0이면 송신하고 수신 ACK로 성공을 확인한다. ACK가 없으면 손실로 보고 contention window를 증가시켜 재시도한다.

### Wi‑Fi는 왜 CSMA/CD를 사용하지 않는가

자기 송신 신호가 다른 단말의 약한 신호를 압도하고 같은 채널에서 송신하면서 충돌을 정확히 감지하기 어렵기 때문이다. 숨은 단말 문제도 있어 충돌 감지만으로 해결하기 어렵다.

### 숨은 단말을 RTS/CTS가 어떻게 완화하는가

AP가 CTS로 주변 단말에 예약 시간을 알리면 송신자를 직접 듣지 못한 숨은 단말도 NAV를 설정해 송신을 미룰 수 있다.

### SSID와 BSSID의 차이는 무엇인가

SSID는 사용자가 보는 네트워크 이름이고 BSSID는 특정 AP의 무선 인터페이스·BSS를 식별한다. 여러 AP가 같은 SSID를 제공하면서 서로 다른 BSSID를 가질 수 있다.

### 2.4GHz와 5GHz의 trade-off는 무엇인가

2.4GHz는 일반적으로 도달 거리와 장애물 통과에 유리하지만 혼잡하고 채널이 적다. 5GHz는 채널과 대역폭이 더 풍부할 수 있지만 거리와 벽 투과가 불리할 수 있다.

### WPA2와 WPA3의 차이는 무엇인가

WPA3-Personal은 SAE와 강화된 관리 프레임 보호를 통해 공유 비밀번호 환경의 보안을 개선한다. WPA2는 일반적으로 CCMP를 사용하지만 약한 PSK 설정은 공격에 취약할 수 있다.

### 로밍하면 TCP 연결이 항상 끊어지는가

항상 그렇지는 않다. 같은 L2·IP subnet 안에서 IP를 유지하며 빠르게 AP를 바꾸면 세션이 유지될 수 있다. IP가 바뀌거나 전환 시간이 길면 연결이 끊길 가능성이 커진다.

### MIMO와 OFDMA의 차이는 무엇인가

MIMO는 여러 안테나와 공간 스트림을 활용하고, OFDMA는 주파수 부반송파 자원을 여러 단말에 나누어 할당한다.

## 핵심 정리

Wi‑Fi는 IEEE 802.11 계열의 무선 LAN 기술로 여러 단말이 같은 채널과 airtime을 공유한다. 자기 송신 신호와 숨은 단말 때문에 충돌을 직접 감지하기 어려워 CSMA/CD 대신 CSMA/CA, 랜덤 backoff, ACK·재전송을 사용한다.

RTS/CTS와 NAV는 숨은 단말로 인한 충돌을 줄일 수 있다. SSID는 네트워크 이름이고 BSSID는 특정 AP·BSS 식별자다. Wi‑Fi 연결은 AP 탐색·Association·보안 키 설정 후 일반적으로 DHCP를 거쳐 IP 설정을 얻는다.

주파수 대역과 채널 폭에는 도달 거리·간섭·처리량의 trade-off가 있다. WPA2·WPA3는 무선 링크의 인증과 암호화를 제공하며, 로밍·전송률 조절·MIMO·OFDMA는 이동성과 무선 자원 효율을 개선한다.
