# 2026-07-13 자료구조·알고리즘 핵심 개념 복습 — 모의면접

> 진행 순서: 해시 테이블 → DP → 그리디 → 배열·동적 배열 → 트리 기초 → NP-completeness
> 현재 종합 이해도: 🟡 보통

## 해시 테이블

### 질문 1. 정의와 동작

**내 답변 요약:** 키-값 자료구조이며, 키에 해시 함수를 적용해 고정 길이 정수를 얻고 테이블 크기로 모듈러 연산하여 인덱스를 계산한다고 설명했다. 서로 다른 키가 같은 인덱스를 갖는 해시 충돌도 언급했다.

**평가:** 기본 동작은 정확했다. 다만 O(1)은 절대 보장이 아니라 균등 분포와 적절한 load factor를 전제로 한 평균·기대 복잡도라는 단서가 필요했다.

### 질문 2. 충돌 해결

**내 답변 요약:** Separate chaining과 open addressing을 구분하고, open addressing의 linear probing·quadratic probing·double hashing을 제시했다.

**평가:** 대표 기법은 알고 있었으나 두 방식의 장단점 설명이 모두 "추가 탐색 비용"에 머물렀다. Chaining은 load factor가 1을 넘을 수 있고 삭제가 쉬우며, open addressing은 cache locality가 좋지만 높은 load factor와 tombstone에 민감하다는 비교가 필요하다.

### 질문 3. Load factor와 rehashing

**내 답변 요약:** 처음에는 사용 중인 버킷 수 / 전체 크기로 설명했으나, 힌트 후 chaining에서는 저장된 전체 원소 수를 기준으로 해야 평균 체인 길이를 반영할 수 있다고 추론했다.

**평가:** Load factor는 α=N/M(저장 원소 수 / 버킷 수)이다. 0.7은 보편적 상수가 아니라 구현별 임계값이다. Chaining은 α>1도 가능하지만 탐색 비용이 증가하고, open addressing은 α가 1에 가까워질수록 급격히 악화된다.

### 질문 4. Clustering

**내 답변 요약:** Linear probing은 연속 점유 구간이 커지는 문제가 있고, quadratic probing은 이를 완화하지만 초기 해시 위치가 같은 키들이 동일한 탐사 순서를 따르는 문제가 남는다고 설명했다.

**평가:** 힌트 후 primary clustering과 secondary clustering을 구분했다. Linear probing은 primary clustering, quadratic probing은 primary를 완화하지만 secondary clustering이 남는다. Double hashing은 키마다 다른 탐사 간격을 사용해 두 현상을 완화한다.

### 질문 5. 삭제

**내 답변 요약:** Open addressing에서 삭제 슬롯을 empty로 만들면 probing 경로가 끊기므로 tombstone으로 표시해야 한다고 설명했다.

**평가:** 정확했다.

### 질문 6. 평균·최악 복잡도와 hash flooding

**내 답변 요약:** 충돌이 적고 해시값이 균등하게 분포하면 평균 O(1), 충돌이 몰리면 O(N)으로 악화될 수 있다고 설명했다. 공격자가 충돌 키를 만들어 오버헤드를 유발할 수 있다는 점도 파악했다.

**평가:** 평균 O(1)의 조건을 균등 해싱과 load factor의 상수 제한으로 구조화할 필요가 있다. 동일 키 반복은 보통 갱신이므로 서로 다른 키의 충돌과 구분해야 한다. Hash flooding 방어로 실행별 무작위 seed를 사용하는 keyed hash, 요청 제한, 충돌 버킷의 균형 BST 전환 등을 복습해야 한다.

### 모범답안

해시 테이블은 키를 해시 함수에 통과시켜 얻은 해시값으로 버킷 인덱스를 계산하고 키-값을 저장하는 자료구조다. 해시값이 균등하게 분포하고 load factor가 적절히 제한된다는 가정에서 삽입·탐색·삭제가 평균 O(1)이지만, 충돌이 몰리면 최악 O(N)까지 악화될 수 있다.

충돌은 separate chaining 또는 open addressing으로 처리한다. Chaining은 한 버킷에 여러 원소를 저장하며 α>1도 가능하다. Open addressing은 다른 빈 슬롯을 탐사하며 α<1이어야 한다. Linear probing은 primary clustering, quadratic probing은 secondary clustering 문제가 있고, double hashing은 키마다 다른 탐사 간격으로 이를 완화한다.

Open addressing에서 삭제 슬롯을 empty로 바꾸면 탐사 경로가 끊기므로 tombstone을 사용한다. Load factor나 tombstone이 늘어나면 더 큰 배열로 rehash한다. 배수 확장 시 rehash를 포함한 삽입은 amortized O(1)이다. Hash flooding은 keyed hash의 무작위 seed, 충돌 체인의 균형 BST 전환, 입력·요청 제한 등으로 완화할 수 있다.

### 약점·복습포인트

- Load factor α=N/M의 정확한 정의
- Primary clustering과 secondary clustering
- 평균 O(1)이 성립하는 조건
- Hash flooding 방어: keyed hash와 균형 BST treeification

## 동적 프로그래밍 (DP)

### 질문 1. 정의와 적용 조건

**내 답변 요약:** 이미 해결한 subproblem을 재사용해 전체 해를 효율적으로 구하며, optimal substructure와 overlapping subproblems가 필요하다고 설명했다. 두 성질의 의미도 정확히 구분했다.

**평가:** 핵심 정의와 적용 조건은 정확했다. 최적화가 아닌 counting·feasibility DP까지 포괄하려면 "부분 문제의 답으로 전체 답을 구성할 수 있는 구조"라고 일반화할 수 있다.

### 질문 2. Memoization과 tabulation

**내 답변 요약:** Memoization은 top-down으로 필요한 상태만 계산하지만 재귀 호출 스택과 cache locality 문제가 있고, tabulation은 bottom-up으로 호출 오버헤드가 없고 cache locality가 좋다고 설명했다.

**평가:** 주요 차이를 잘 설명했다. 다만 tabulation이 항상 메모리를 더 쓰는 것은 아니다. 두 방식 모두 상태 수만큼 저장할 수 있고, tabulation은 의존 범위가 제한되면 rolling array로 공간을 더 줄일 수 있다.

### 질문 3. 계산 순서

**내 답변 요약:** Base 상태를 먼저 계산하고 이후 상태가 이전 단계의 값만 참조해야 한다고 설명했다.

**평가:** 방향은 맞지만 상태 의존 관계로 계산 순서를 구체적으로 정당화하지 못했다. DP 설계에서는 상태 정의·점화식·base case·계산 순서를 함께 제시해야 한다.

### 질문 4. 0/1 Knapsack의 1차원 공간 최적화

**내 답변 요약:** 같은 단계에서 갱신된 값을 즉시 다시 참조하면 오염된 값이 전파될 수 있다는 원리는 파악했지만, 문제 상황과 점화식 및 구체적인 예시는 설명하지 못했다.

**평가:** 주요 약점이다. 0/1 Knapsack은 용량을 내림차순으로 순회해 dp[w-w_i]가 이전 물건 단계의 값으로 남게 해야 한다. 오름차순이면 현재 물건으로 갱신된 값을 다시 사용해 같은 물건을 여러 번 선택하는 Unbounded Knapsack 동작이 된다.

### 모범답안

DP는 중복되는 부분 문제의 답을 저장·재사용하는 기법이다. 부분 문제의 답으로 전체 답을 구성할 수 있고 동일한 부분 문제가 반복 등장할 때 효과적이다. Memoization은 top-down으로 필요한 상태만 재귀 계산하고, tabulation은 의존 관계에 맞는 순서로 테이블을 채운다.

0/1 Knapsack의 점화식은 dp[i][w] = max(dp[i-1][w], dp[i-1][w-w_i] + v_i)이다. 1차원으로 줄이면 dp[w] = max(dp[w], dp[w-w_i] + v_i)이며, 용량을 큰 값부터 순회해야 현재 물건이 한 번만 반영된다. 예를 들어 무게 2, 가치 3인 물건 하나와 용량 4에서 오름차순이면 dp[2]=3을 갱신한 뒤 dp[4]=dp[2]+3=6으로 만들어 같은 물건을 두 번 사용한다. 내림차순이면 dp[4]가 갱신 전 dp[2]를 참조하므로 한 번만 사용한다. Unbounded Knapsack은 중복 사용이 허용되므로 오름차순이 맞다.

### 약점·복습포인트

- DP 상태 정의·점화식·base case·계산 순서를 함께 설명하기
- Tabulation이 항상 memoization보다 메모리를 더 쓰는 것은 아님
- 0/1 Knapsack 1차원 최적화는 용량 내림차순
- Unbounded Knapsack은 용량 오름차순

## 그리디 알고리즘

### 질문 1. 정의와 적용 조건

**내 답변 요약:** 각 단계에서 현재 가능한 locally optimal한 선택을 취해 global optimum을 달성하는 알고리즘이라고 설명했다.

**평가:** 지역 최적 선택을 반복한다는 기본 방향은 맞았지만, 최적해 보장 조건을 함께 설명하지 못했다.

### 질문 2. 최적해를 보장하는 두 성질

**내 답변 요약:** Optimal substructure는 기억했지만 greedy choice property를 떠올리지 못했고, 힌트 후에도 exchange argument와 혼동했다.

**평가:** 주요 약점이다. Greedy choice property는 현재의 그리디 선택을 포함하는 최적해가 항상 존재해 선택을 되돌릴 필요가 없다는 성질이다. Exchange argument는 이 성질 자체가 아니라, 최적해의 선택을 그리디 선택으로 교체해도 해가 나빠지지 않음을 보여주는 증명 기법이다.

### 모범답안

그리디 알고리즘은 각 단계에서 현재 기준으로 가장 좋은 선택을 하고 이전 선택을 되돌리지 않으면서 전체 해를 구성한다. 최적해를 보장하려면 greedy choice property와 optimal substructure가 필요하다.

Greedy choice property는 현재의 그리디 선택을 포함하는 최적해가 항상 존재한다는 성질이다. Optimal substructure는 그 선택 이후 남은 부분 문제의 최적해를 결합하면 전체 최적해가 된다는 성질이다.

Exchange argument는 임의의 최적해가 그리디 선택과 다르다고 가정한 뒤, 그 선택을 그리디 선택으로 교체해도 목적함수 값이 나빠지지 않음을 보여 greedy choice property를 증명하는 기법이다.

### 약점·복습포인트

- Greedy choice property의 이름과 의미 즉시 회상
- Optimal substructure는 DP와 공유하는 성질
- Exchange argument는 조건이 아니라 정확성 증명 기법
- 이전 학습에서도 같은 약점이었으므로 우선 복습

## 배열·동적 배열

### 질문 1. 배열과 연결 리스트 비교

**내 답변 요약:** 배열은 연속 메모리를 사용해 random access가 O(1)이고, 끝이 아닌 위치의 삽입·삭제는 원소 이동 때문에 O(N)이라고 설명했다.

**평가:** 정확했다. 주소를 base + index × element_size로 명시하면 더 완결된 답이 된다.

### 질문 2. Cache locality

**내 답변 요약:** 배열은 연속 메모리라 주변 값이 함께 캐시에 올라와 spatial locality와 cache hit 측면에서 유리하다고 설명했다. 연결 리스트는 노드가 서로 다른 메모리 위치에 있다고 답했다.

**평가:** 배열의 spatial locality는 설명했지만 cache line과 hardware prefetcher, pointer chasing의 의존적 cache miss를 충분히 설명하지 못했다.

### 질문 3. 동적 배열의 size·capacity와 확장

**내 답변 요약:** Size는 현재 원소 수, capacity는 허용 가능한 크기이며, 가득 차면 배열을 확장한다고 설명했다. 단일 확장은 O(N), 2배 확장 시 append가 amortized O(1)임을 알고 있었다.

**평가:** 정확했다.

### 질문 4. 확장 배율에 따른 총복사 비용

**내 답변 요약:** 2배 확장은 한 번의 O(N) 비용이 이후 삽입들에 상환된다고 설명했지만, 고정 크기 c 확장의 전체 비용을 O(N)으로 잘못 계산했고 힌트 후에도 등차수열 합을 구하지 못했다.

**평가:** 주요 약점이다. 2배 확장의 복사량은 1+2+4+...<N이라 전체 O(N), append당 amortized O(1)이다. 고정량 c 확장은 c+2c+...+(N/c)c=Θ(N²/c)이고, c가 상수면 전체 Θ(N²), append당 amortized Θ(N)이다.

### 모범답안

배열은 연속 메모리에 동일 크기 원소를 저장하며 i번째 주소를 base+i×element_size로 계산해 random access O(1)을 지원한다. 중간 삽입·삭제는 뒤 원소를 이동해 O(N)이다. Cache line 단위 로드와 규칙적 stride 덕분에 spatial locality와 hardware prefetching에 유리하다. 연결 리스트는 다음 주소를 현재 노드에서 읽어야 하므로 pointer chasing으로 인한 의존적 cache miss가 발생하기 쉽다.

동적 배열은 size와 capacity를 구분하며, 가득 차면 더 큰 배열을 할당해 기존 원소를 복사한다. 2배 확장은 N번 append 동안 총복사 비용이 O(N)이라 append당 amortized O(1)이다. 고정량 c 확장은 총복사 Θ(N²/c), c가 상수면 append당 amortized Θ(N)이다.

### 약점·복습포인트

- Cache line·hardware prefetcher·pointer chasing을 연결해 설명
- 2배 확장의 등비급수 총복사 O(N)
- 고정량 c 확장의 등차수열 총복사 Θ(N²/c)
- 전체 비용과 append당 amortized 비용 구분

## 트리 기초

### 질문 1. 정의와 기본 용어

**내 답변 요약:** 트리를 N개 정점과 N-1개 간선을 가진 그래프로 설명한 뒤 모든 노드가 연결되어야 한다고 보충했다. Root·leaf·depth는 설명했지만 sibling을 빠뜨렸고, height를 root 기준 거리로, degree를 연결된 모든 간선 수로 혼동했다.

**평가:** 트리는 연결된 비순환 무방향 그래프로 정의하는 것이 안전하다. Rooted tree에서 depth는 root에서 노드까지 거리, 노드의 height는 그 노드에서 가장 먼 leaf까지 거리, 트리 height는 root의 height, degree는 child 수다. 힌트 후 예시 계산은 정확했다.

### 질문 2. Full·complete·perfect binary tree

**내 답변 요약:** 처음에는 full과 complete의 정의를 뒤바꿨지만 재질문 후 full은 모든 노드의 child가 0개 또는 2개, complete는 마지막 레벨을 제외하고 가득 차며 마지막 레벨이 왼쪽부터 채워진다고 수정했다. Perfect는 두 조건을 모두 만족한다고 설명했다.

**평가:** 수정 후 정확했다.

### 질문 3. Tree traversal

**내 답변 요약:** Preorder=root-left-right, inorder=left-root-right, postorder=left-right-root를 정확히 답했고 반복 구현에는 stack을 쓴다고 설명했다. Level-order는 queue 기반 BFS이며 재귀 호출도 call stack을 사용한다고 설명했다.

**평가:** 정확했다.

### 질문 4. 포인터·배열 표현

**내 답변 요약:** 포인터 기반 표현은 노드 간 연결 관계를 저장하고, 배열 기반 표현은 인덱스 규칙으로 parent-child 관계를 나타낸다고 설명했다. Complete tree는 빈 슬롯이 없지만 편향·희소 트리는 빈 슬롯이 많아 비효율적이라고 답했다.

**평가:** 정확했다.

### 질문 5. N개 정점·N-1개 간선인 연결 그래프의 비순환성 증명

**내 답변 요약:** 사이클이 있으면 연결될 수 없다고 답했으며, 사이클 간선 하나를 제거해도 연결성이 유지된다는 힌트 후 N-2개 간선으로 N개 정점을 연결하는 것이 불가능하다고 설명했다. 다만 최소 N-1개 간선이 필요한 이유를 엄밀하게 전개하지 못했다.

**평가:** 주요 약점이다. 한 정점에서 시작해 나머지 N-1개 정점을 연결 요소에 새로 포함하려면 간선이 최소 N-1개 필요하다. 사이클 간선 하나를 제거해 연결된 N정점·N-2간선 그래프를 만들 수 있다는 가정은 이 하한과 모순이다.

### 모범답안

트리는 연결된 비순환 무방향 그래프다. 동치로 임의 두 정점 사이 경로가 정확히 하나 존재하며, N개 정점이면 간선은 N-1개다. Depth는 root에서 노드까지 거리, height는 노드에서 가장 먼 leaf까지 거리, rooted tree의 degree는 child 수다.

Full binary tree는 모든 노드의 child가 0개 또는 2개이고, complete binary tree는 마지막 레벨 전까지 가득 차고 마지막 레벨이 왼쪽부터 채워진다. Perfect binary tree는 모든 내부 노드의 child가 2개이고 모든 leaf가 같은 depth에 있다.

Preorder·inorder·postorder는 stack 또는 재귀를, level-order는 queue를 사용한다. 배열 표현은 complete tree에 효율적이고 편향·희소 트리에는 빈 슬롯 낭비가 크다.

### 약점·복습포인트

- Depth와 height의 기준 방향 구분
- Rooted tree에서 degree는 child 수
- Full·complete·perfect 정의 즉시 구분
- 연결된 N개 정점에는 최소 N-1개 간선이 필요하다는 증명
- 사이클 간선 제거 논증과 연결해 비순환성 증명
