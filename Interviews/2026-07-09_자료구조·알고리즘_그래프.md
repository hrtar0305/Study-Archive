## 개념: 그래프 (표현·탐색·최단경로)

### Q1~Q2. 그래프 표현
- **내 답변 요약**: 인접 리스트(간선 수만큼 공간, 연결확인은 해당 노드의 간선 수) vs 인접 행렬(N² 공간, 연결확인 O(1)). dense면 행렬, sparse면 리스트.
- **평가**: 정확. **보완** — 인접 리스트 공간은 정확히 O(V+E), 연결확인은 O(degree(u)).

### Q3~Q5. BFS/DFS와 최단경로 보장
- **내 답변 요약**: BFS=큐·FIFO, DFS=스택·LIFO. BFS는 동일 가중치 최단거리, DFS는 백트래킹. BFS 보장 논리 = 가까운 순서로 삽입되어 pop 순서가 거리 순, 재방문은 무시. DFS는 한 경로 끝까지 우선이라 보장 없음.
- **평가**: 정확. "레벨 단위 확장이라 처음 도달=최단"이라는 표현이 더 깔끔.

### Q6~Q8. 가중치 그래프와 다익스트라의 한계
- **내 답변 요약**: 가중치가 다르면 큐 삽입 순서=거리 순서 전제가 깨져 BFS 불가 → 다익스트라. 다익스트라는 우선순위 큐 그리디로 미방문 노드가 처음 pop될 때 최단거리 확정(finalize)되는데, 음의 가중치는 확정된 값을 나중에 갱신해야 하므로 모순 → 불가.
- **평가**: 정확. 지난 세션 약점(비음 조건이 증명에 쓰이는 지점)이 완전히 해소됨.

### Q9~Q10. 벨만-포드 vs 플로이드-워셜
- **내 답변 요약**: 벨만-포드=단일 출발점, 플로이드-워셜=전체 쌍. 복잡도는 처음 O(V²)/O(V³)로 답 → 힌트("모든 간선을 V번 relax") 후 벨만-포드를 O(VE)로 정정.
- **약점(정정됨)**: 벨만-포드 복잡도 O(VE) 즉시 상기 실패.
- **모범답안 보강**: sparse면 벨만-포드 유리. 음의 간선 없으면 다익스트라 O((V+E) log V)가 항상 더 빠름.

### 사용자 요청 — 음의 사이클 (해설)
- **정의**: 한 바퀴 가중치 합이 음수인 사이클. 돌수록 짧아져 거리 -∞ 발산 → 최단경로 개념 자체가 무의미 (알고리즘 한계가 아니라 문제의 답이 없는 상황).
- **음의 간선 ≠ 음의 사이클**: 간선만 음수면 벨만-포드로 정확히 풀 수 있음.
- **벨만-포드 탐지**: 음의 사이클 없으면 최단경로 간선 수 ≤ V-1 → V-1번 전체 이완으로 확정 → **V번째 이완에서도 갱신되면 음의 사이클 존재**.
- **플로이드-워셜 탐지**: dist[i][i] < 0인 정점 존재 시.
- **실무**: 환율 차익거래(arbitrage) 탐지 — 로그 변환 후 음의 사이클 찾기.

### 약점·복습포인트 (그래프)
- 벨만-포드 O(VE) — "V번 반복 × E개 간선 relax" 구조로 기억
- 인접 리스트 공간 O(V+E)
- 음의 간선/음의 사이클 구분, V번째 이완 탐지 원리
